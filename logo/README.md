# Assetment logo

A gold **A** made of six stacked bars, then "ssetment". See [preview.html](preview.html).

## Variants

Each comes as a **logo** (with text) and an **icon** (A only).

| # | Variant | Use on |
|---|---|---|
| 1 | [Gold A, light text](final/1-gold-light-text/) | Dark backgrounds |
| 2 | [Gold A, ink text](final/2-gold-ink-text/) | Light backgrounds (main) |
| 3 | [All gold](final/3-gold/) | Light or dark |
| 4 | [All ink](final/4-ink/) | Light backgrounds |

Each folder has `-logo.svg`, `-icon.svg` and transparent PNGs in `png/` at 512, 256, 64 and 32 px. Prefer SVG. Text is outlined.

## Colours

| Name | HEX | RGB |
|---|---|---|
| Gold | `#a47a22` | 164, 122, 34 |
| Ink | `#0f1e18` | 15, 30, 24 |
| Light | `#eaf2ef` | 234, 242, 239 |

## Font

[Fraunces](https://fonts.google.com/specimen/Fraunces) (SIL Open Font License): weight 650, optical size 72, Soft 100, Wonk 0.

## Rules

- **Minimum size:** logo 16 px tall (smaller, use the icon); icon 16 px.
- **Clear space:** half the A's height on every side.
- Don't recolour, stretch, rotate or add effects.
- Don't retype the name in a live font.
