# J6 – Sign in and come back

**Persona:** salaried investor ([product.md](../product.md))

**Goal:** get back to their numbers, safely, in seconds.

| # | Step | Screen | Features |
|---|------|--------|----------|
| 1 | Sign in with email and password | Sign in | F23, F19 |
| 2 | Forgot the password: ask for a reset link by email | Forgot password | F24 |
| 3 | Open the link and set a new password | Reset password | F24 |
| 4 | If two-step sign-in is on, type the code from an authenticator app | Sign-in code | |
| 5 | Land on Home, or back on the page they tried to open | Dashboard | F01, F23 |
