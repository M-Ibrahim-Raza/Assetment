# Journeys

The main tasks a user comes to Assetment to do. Persona for all journeys: salaried investor ([product.md](product.md)). `Features` is filled in while building the prototype.

## J1 – Set up and see net worth

**Goal:** get all money into the app once and see net worth.

| # | Step | Screen | Features |
|---|------|--------|----------|
| 1 | Sign up | Sign up | |
| 2 | Add bank, wallet and cash accounts with opening balances, in PKR or a foreign currency | Add account | |
| 3 | Add gold and silver by weight | Add asset | |
| 4 | Add PSX stocks and funds as buys | Add trade | |
| 5 | Add property and plots with a value entered by hand | Add asset | |
| 6 | Add debts: loans, card balances, committees | Add debt | |
| 7 | See today's net worth | Dashboard | |

## J2 – Log money in or out

**Goal:** record an expense, income or transfer in seconds, with balances and net worth kept up to date.

| # | Step | Screen | Features |
|---|------|--------|----------|
| 1 | Tap Add from any screen | Quick add | |
| 2 | Pick expense, income or transfer | Quick add | |
| 3 | Enter amount, category and account, or scan a receipt | Quick add | |
| 4 | Check the details read from the receipt and fix any errors | Receipt review | |
| 5 | Save. The account balance and net worth update | Dashboard | |

## J3 – See where money goes

**Goal:** know where this month's money went and how it compares with last month.

| # | Step | Screen | Features |
|---|------|--------|----------|
| 1 | Open spending for this month, by category | Spending | |
| 2 | Compare with last month | Spending | |
| 3 | Open a category to see its entries | Category detail | |
| 4 | Edit or delete an entry | Entry detail | |

## J4 – Track investments

**Goal:** see what each stock and fund is worth and how much it has gained or lost.

| # | Step | Screen | Features |
|---|------|--------|----------|
| 1 | Open the portfolio | Portfolio | |
| 2 | Log a buy or sell: stock or fund, quantity, price, date | Add trade | |
| 3 | See each holding's quantity, average cost, value and profit or loss, plus the total | Portfolio | |
| 4 | Open a holding to see its trades | Holding detail | |

## J5 – Watch net worth over time

**Goal:** see whether net worth is growing and how it's split.

| # | Step | Screen | Features |
|---|------|--------|----------|
| 1 | Open net worth over time | Net worth | |
| 2 | See how net worth splits across cash, gold, stocks, property and debts | Net worth | |
| 3 | Update a property value or a debt balance | Asset detail, Debt detail | |
